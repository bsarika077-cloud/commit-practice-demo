# Commit Practice Demo

## Project Overview

This project demonstrates proper Git commit messages
and a clean folder structure.

## Folder Structure

- src/ - Contains application logic.
- tests/ - Contains testing scripts.
- docs/ - Contains project documentation.
- assets/ - Stores images and resources.

## Technologies Used

- Git
- GitHub
- JavaScript
- Markdown

## Objective

To practice meaningful commits and GitHub version control.
